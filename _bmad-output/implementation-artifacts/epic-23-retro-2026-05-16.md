# Epic 23 Retrospective

## What was built

**23-1 — Position flip and exchange fallback**
Added `_current_side: str | None` state tracking to `OFIBot` and `MACrossBot`. Both bots now
issue an exit order before flipping to the opposite side; gaps reset `_current_side` to `None`.
8 new tests (5 for MACrossBot, 3 for OFIBot) validate hold-when-same-side, flip-exit+entry,
and gap-reset behaviour.

**23-2 — BaseStrategy TF→table routing + max_position_pct guard**
`_TF_TABLE` dict in `base.py` maps tf strings to the correct QuestDB snapshot table
(snapshot_1s / snapshot_1m / snapshot_15m). `_query_questdb` now derives `table` from the
mapping instead of hardcoding `snapshot_1s`. `__init__` raises `ValueError` if
`max_position_pct ≤ 0` or `> 1.0`. 8 parametrized tests cover 6 TF variants, unknown-TF
fallback, and both validation bounds.

## What went well

- State machine pattern (`_current_side`) is minimal and testable without mocking asyncio.
- Initializing `_current_side` in `__init__` rather than `subscribe()` avoids hidden test
  setup requirements — tests can call `_on_bar` directly without calling `subscribe` first.
- Parametrized pytest for TF routing eliminated boilerplate while covering all required cases.
- The `_TF_TABLE` is a module-level constant, not a class attribute, which avoids confusion
  about whether subclasses can override it.

## Lessons learned

- `__init__` is the right place for invariant validation (max_position_pct, orderbook_mode):
  fail-fast at construction, not at the first order.
- When backfilling deferred items (D-15-x-x), prefer atomic story-sized commits so git history
  shows which deferred item each commit addresses.

## Deferred

None — all acceptance criteria met.
